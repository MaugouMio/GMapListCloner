# Google Map List Cloner

幫你複製其他人的 Google 地圖清單，匯入自己的清單中 (並不保證景點順序)

## 如何安裝
1. 點選右上綠色 Code 按鈕，選擇最下面的 `Download ZIP`
2. 開啟下載的壓縮檔，把裡面的資料夾拖出來
3. 前往 chrome://extensions/ 右上角開啟 `開發人員模式`
4. 左上方點選 `載入未封裝項目`
5. 選擇剛剛拖曳出來的資料夾
6. 在 Google Map List Cloner 區塊中點選 `詳細資料`
7. 找到 `在工具列中固定` 選項並開啟

## 如何使用
1. 確認已登入要匯入清單的 Google 帳號
2. 開啟要複製的 Google 地圖清單 (請勿點開任何景點)
3. 點選擴充功能工具列在安裝時新增的圖示
4. 點選 `開始擷取清單`
5. 系統會花一段時間遍歷所有景點，**期間內請不要進行操作**
6. 輸入要匯入的清單名稱 (請先自行建立清單) 並點選 `複製此清單`
   - 可以設定同時開啟的分頁數量，效能允許的情況下越多越快
7. 系統會同時開啟多個分頁自動儲存到指定清單，**期間內請不要進行操作**
   - 若發現開啟的分頁圖示變成 Google 首頁，可能是被判定為機器人，請手動開啟那些分頁點選 `我不是機器人`
9. 完成後系統會顯示提示
